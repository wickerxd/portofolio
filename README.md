# work-portfolio

Personal portfolio for Dimitrios Karamatskos.

Built with React and Vite. Styling is plain CSS using the tokens in
`src/styles/main.css`.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run lint
npm run build
npm run preview
```

## Content

All copy and links live in `src/data/content.js`. Replace the `href: '#'`
placeholders with the real project and social URLs.
